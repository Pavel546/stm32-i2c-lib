# Bare-Metal I2C Driver for STM32F401

Низкоуровневый драйвер I2C (режим Master) для микроконтроллера STM32F401CCU6. Реализован без использования сторонних библиотек (HAL, LL, CMSIS) через прямое управление регистрами.

## Спецификация и параметры
* **Периферия:** I2C1
* **Выводы:** PB6 (SCL), PB7 (SDA)
* **Режим портов:** Альтернативная функция (AF4), Open-Drain, встроенная подтяжка (Pull-up)
* **Режим I2C:** Standard Mode, 100 кГц
* **Тактирование:** Параметры CCR и TRISE рассчитываются динамически на основе переданной частоты шины APB1.

## Структура проекта
* `include/registers.h` — Базовые адреса и смещения регистров RCC, GPIOB, I2C1.
* `include/i2c.h` — Прототипы функций интерфейса драйвера.
* `src/i2c.c` — Логика инициализации, обработки флагов автомата состояний I2C и передачи данных.
* `examples/main.c` — Пример использования драйвера для управления дисплеем SSD1306 (OLED 0.91").

## Описание API
* `I2C1_Init(uint32_t APB1_clock_mhz)` — Инициализация модуля I2C1 и настройка выводов SCL/SDA. (APB1_clock_mhz частота шины APB1 в МГц)
* `I2C1_Start(void)` — Формирование сигнала СТАРТ (START) на шине.
* `I2C1_Stop(void)` — Формирование сигнала СТОП (STOP) на шине.
* `I2C1_SendAddress(uint8_t address, uint8_t direction)` — Отправка адреса устройства. Параметр direction задает режим: 0 — запись, 1 — чтение.
* `I2C1_Write(uint8_t data)` — Отправка одного байта данных ведомому устройству.
* `I2C1_Read(uint8_t address)` — Чтение одного байта данных из ведомого устройства с указанным адресом.
